# TASK-007 거래 상세·필터·정렬

상태: 완료(사용자 승인 대기) · 2026-10-24

## 목적
최근 12개월 매매/전월세, 계약일·면적·층·금액·출처·최신성, 필터/정렬

## 완료 기준
확정 매칭 거래만 표시, 정상 빈 결과와 장애 구분

## 공통 지침
- docs/PRD.md 및 docs/SECURITY_COST.md 준수
- 외부 API 실제 호출 전 사용자 승인
- API Secret 노출 금지; 월 0원 운영 조건 위반 금지
- 테스트 결과·근거·미해결 사항 기록 후 다음 단계 승인 대기

## 결과 (2026-10-24)
- API: 거래 목록(유형·기간·면적·정렬 6종·페이지), 거래 단건. 기간은 최근 12개 계약월 안에서만 허용하고, 입력 오류는 400으로 응답한다
- 노출 규칙: 확정 매칭 + ACTIVE만 노출. 해제·MISSING·미매칭은 목록과 단건 모두 제외(테스트로 확인)
- 상태 구분: 거래 없음(정상 빈 결과) / 특정 월 수집 실패(누락 월 안내) / 갱신 지연 / 서버 장애(오류 + 다시 시도)
- 화면(SCR-003): 매매·전월세 탭(건수), 면적 칩, 정렬, 20건씩 더 보기, 행을 펼치면 상세(등기일·동 / 보증금·월세·신규/갱신·계약기간), 출처·갱신 시각·신고 기한 안내
- 발견·수정: 상세 화면에서 다른 단지로 이동해도 이전 단지의 탭·필터가 남던 문제(E2E로 발견)
- 테스트: 단위·통합 93개 + E2E 17개 항목 통과
- 한계: 전월세 가격 정렬은 보증금 기준(전·월세 환산 없음). `/api/transactions/{id}`는 API만 있고 별도 화면은 없음(목록 행 펼치기로 대체)
