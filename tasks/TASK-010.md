# TASK-010 첫 화면 대시보드: 제주시/서귀포시 가장 비싼 아파트

상태: 구현 완료(2026-10-24), 배포 환경 확인·사용자 승인 대기

## 사용자 결정 (2026-10-24)
- 순위 기준: 최고 매매가와 평당가를 탭으로 모두 제공
- 표시: 시별 TOP 5
- 배치: 상단에 '대시보드' 탭을 추가하고 첫 화면으로
- 특이 거래: 가공하지 않고 그대로 표시, 그 거래의 면적·층·계약일을 함께 노출

## 집계 규칙
- 대상: 최근 12개월(현재 월 포함, KST) 계약된 매매 중 확정 매칭(`apartment_id` 있음) + `ACTIVE`. 해제·사라진 거래·미매칭·전월세 제외(상세 API와 같은 공개 규칙)
- 단지마다 기준값이 가장 높은 거래 1건이 그 단지를 대표하고, 시별로 순위를 매김(동점은 단지 ID 순)
- 평당가 = 거래금액 ÷ (전용면적 ÷ 3.3058). 단지 대표 거래는 탭(기준)마다 따로 고름
- 외부 API 호출 없음(DB만 조회), CDN 캐시 300초

## 구현
- API: `GET /api/dashboard/top-apartments` (`server/handlers/dashboard.ts`, `api/dashboard/top-apartments.ts`)
- 화면: `src/components/Dashboard.tsx`. 화면 전환을 해시 주소로 변경 — `#/` 대시보드(첫 화면), `#/map` 지도, `#/list` 목록, `#/apartments/{id}` 상세. 상세의 '← 돌아가기'는 이전 화면으로 이동
- 대시보드에서는 지역 선택·검색창을 숨김(두 시를 함께 보여주므로)

## 테스트
- `tests/dashboard.db.test.ts`: 순위·TOP 5·해제/미매칭/기간 밖/전월세 제외·평당가 계산·탭별 대표 거래·DB 장애 503
- `tests/security.test.ts`: 설정 오류 시 대시보드 API도 503
- E2E(`tests/e2e/map.e2e.mjs`, `outage.e2e.mjs`)를 대시보드 첫 화면에 맞게 수정. 실데이터 개발 DB가 없어 이 환경에서는 미실행 — 대신 시험 데이터로 브라우저(390px) 확인: 5+5행, 탭 전환, 상세 이동·복귀, 목록 탭, 가로 넘침·페이지 오류 없음

## 미검증·위험
- 실데이터 순위 결과는 배포 환경에서 확인 필요(소형 평형 1건이 평당가 상위를 차지할 수 있음 — 결정대로 그대로 표시)
- E2E 실데이터 실행은 개발 DB 복원 후 가능
