# Phase 2 Claude Code 개발 이관 계획

> 상태: 최종 승인 반영 설계 문서 / 실제 API·DB·요금제 검증 및 구현 미수행. Claude Code에서 현행 코드 확인 후 수행.
> 범위: Phase 2 신규 파일만 추가. Phase 1 파일 수정 금지. 기능 플래그 기본 OFF. 사용자 수동 공개 승인 필수.

## 절대 금지
Phase 1 파일 덮어쓰기·기존 API 계약 변경·실제 운영 DB 무단 변경·비밀키 출력·과금 가능한 서비스 무승인 사용·기능 플래그 임의 ON·사용자 승인 없는 공개 배포 금지.

## 실행 순서 / 작업
1. P2-TASK-001 현행 저장소/스키마/API/무료 한도 **검증 계획과 차이 보고** (실행은 Claude Code에서).
2. P2-TASK-002 Phase 2 데이터 모델·안전한 마이그레이션/롤백 설계.
3. P2-TASK-003 유효 거래·월별 집계·원본 기간 통계·버전 처리.
4. P2-TASK-004 분석 API·근거 거래 커서·캐시/보안.
5. P2-TASK-005 기존 상세에 가격 분석 탭·반응형·접근성.
6. P2-TASK-006 30개 TC·데이터 품질·Phase 1 회귀·성능 검증.
7. P2-TASK-007 비용·장애·플래그·배포 게이트 증거 정리 후 **사용자 승인 요청**.

## 단계별 확인 게이트
G1 현행 스키마/API/원천 응답/무료 한도 확인 → 사용자에게 차이·위험 보고. G2 마이그레이션 리뷰. G3 집계·캐시 일관성 검증. G4 UI/회귀 검증. G5 비용·장애·수동 배포 승인. 각 게이트 전 후속 위험 작업 보류.

```text

Secret은 출력하지 마라. 구현은 승인된 Phase 2 전용 브랜치/파일에서만 진행하고 기능 플래그는 기본 OFF로 유지하라. 공개 배포는 테스트 증거 검토 후 사용자 수동 승인을 받아라.
