# 제주 부동산 실거래 통합 검색 Phase 2 — 가격 분석 PRD v1.1

> 상태: 최종 승인 반영 설계 문서 / 실제 API·DB·요금제 검증 및 구현 미수행. Claude Code에서 현행 코드 확인 후 수행.
> 범위: Phase 2 신규 파일만 추가. Phase 1 파일 수정 금지. 기능 플래그 기본 OFF. 사용자 수동 공개 승인 필수.

## 1. 목적과 비범위
제주시(50110)·서귀포시(50130) 아파트 **매매** 실거래에 한해 단지별 면적 유형 가격 추이·거래량·통계·12개월 비교를 제공한다. 전월세 분석, 유사 단지 비교, 예측, 로그인, 알림은 제외한다. Phase 1 지도·검색·매매/전월세 조회는 유지한다.

## 2. 확정 결정
- 분석기간: 현재 한국시간 계약월 포함 12/24/36개월, 기본 24개월.
- 전용면적 유형: 양수 면적의 floor(area_m2 + 0.5), 예: 84.49→84㎡, 84.50→85㎡. 원본 정밀 면적 보존.
- 대표가격: **동일 단지·동일 면적 유형** 유효 거래의 중위가격. **기간 전체** 3건 이상일 때 표시. 월별 중위가격은 표시하지 않는다(v1.1, D12).
- 가격 그래프(v1.1): 선택 면적 유형의 유효 거래를 **계약일별 개별 점**으로 모두 표시(점 1개 = 근거 거래 1건). 보조선으로 **분기 중위가격**을 분기 3건 이상인 분기에만 표시.
- 전체 면적(all): 거래량만 표시. 전체 면적 원화 대표가격·변화율·㎡당 대표가격 미표시.
- 가격 변화율: 최근 12개 계약월과 직전 12개 계약월의 중위가격 비교, 각 3건 이상 및 양 기간 수집 완전성 충족 시만 표시. 12개월 UI 선택 시에도 24개월 비교 데이터 필요.
- 근거 거래: 집계 대상 전체를 버전 일치 페이지 조회. 취소·중복·미확정 매칭 제외.
- 월별(거래량)·분기(보조선 중위) 사전 집계 + 기간 전체 원본 거래 집계. 단지별 데이터 버전으로 캐시 무효화.
- 마지막 정상 수집 후 48시간 초과 시 갱신 지연 경고. 현재 계약월은 집계 진행 중 별도 표시.
- 무료 운영 목표 월 0원. 비용 위험 시 비필수 수집·재집계 중단, 기존 검증된 정상 데이터는 **지연 표시와 함께** 제공. 과금 차단 불확실 시 공개 보류.
- Phase 2 서버·UI 기능 플래그 기본 OFF. 테스트 증거 검토 후 사용자 수동 공개 승인.

## 6. 필수 보완·불확실성
- Phase 1 문서는 설계이며 실제 코드/DB 스키마는 확인되지 않았다. 호환성 검증 전 마이그레이션 실행 금지.
- 거래 정정·취소 식별자, 월별 수집 완전성의 정확한 판정, API 실제 응답, 공급자 약관은 미검증.
- '완료'는 **수집 작업 성공**이지 최종 거래 신고 확정이 아니다. 지연 신고·사후 정정 가능성을 UI에 고지.
- 분석 버전은 집계값뿐 아니라 근거 거래·수집 완전성 스냅샷을 일관되게 가리켜야 한다. 재계산 중 불일치 노출 금지.
- 최신 월이 부분 진행 중이더라도 수집 작업이 정상 완료된 시점까지의 잠정 값임을 표시. 수집 실패 시 0건 처리 금지.
- 데이터 품질/성능 목표는 실제 검증 후 재조정하고 변경은 승인받는다.

## 7. 변경 이력
- v1.1 (2026-10-25, 사용자 승인): 운영 DB 실측(P2-TASK-001 보고서 8절, D12) 결과 12개월 기준 단지×면적 묶음의 79%가 3건 미만, 단지×면적×월 칸당 약 1.2건으로 "월 3건 이상" 월별 중위가격은 대부분 표시 불가. 가격 그래프를 **개별 거래 점 + 분기 중위 보조선(분기 3건 이상)**으로 바꾸고 월별 중위가격 표시를 제거. 기간 통계(3건 이상)·변화율·거래량·근거 거래 규칙은 유지. 변경: 2절 대표가격·가격 그래프·사전 집계, 3절 SC-005·P2-SCR-003, 4절 P2-FR-005·006.
