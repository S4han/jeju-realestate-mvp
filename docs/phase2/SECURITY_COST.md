# Phase 2 보안·무료 운영·장애 대응

> 상태: 최종 승인 반영 설계 문서 / 실제 API·DB·요금제 검증 및 구현 미수행. Claude Code에서 현행 코드 확인 후 수행.
> 범위: Phase 2 신규 파일만 추가. Phase 1 파일 수정 금지. 기능 플래그 기본 OFF. 사용자 수동 공개 승인 필수.

## 보안
국토부 키/DB Secret 서버·CI 전용, 로그/응답/번들 노출 금지. 지도 공개 앱 키는 도메인 제한. 기간·면적·ID·정렬·페이지 크기 서버 검증, SQL 파라미터 바인딩, 커서 위변조 방지, 요청률 제한. 개인정보 최소 수집, 거래 조회 로그 보존 최소화. Phase 1 기존 정책 상속.

## 월 0원 운영
공급자별 무료 한도/사용조건/상업적 이용/과금 자동 전환/계정 결제 설정을 Claude Code에서 최신 공식 문서와 실제 계정으로 검증. 무료 예산 80% 경고; 한도 도달·예상 초과 시 비필수 과거 수집·재집계 중단. 기존 **검증된** 결과만 STALE 표시와 함께 제공. 데이터 불완전/불일치 결과는 제공 금지. 서버 제한만으로 공급자 과금 방지 불가능하므로 공급자 측 강제 한도/결제 차단 검증 안 되면 공개 보류.

## 장애·복구
분석 API 장애 → 분석 탭 오류/재시도, Phase 1 기능 유지. 집계 실패 → 이전 정상 버전 유지 + 갱신 지연 안내. 수집 실패 → 미수집을 거래 0건으로 표시 금지. 캐시 불일치 → 차단/재계산. 공용 DB 장애 → Phase 1 영향 가능성 명시. 통계 오류·비용 위험 → 서버/프론트 기능 플래그 OFF, 기존 Phase 1 서비스 유지. 공개 전 테스트 증거 사용자 검토·수동 승인.

## 최신성
마지막 정상 수집 시각 이후 48시간 **초과**하면 STALE 경고. 성공한 수집도 해당 시점 기준 잠정 결과이며 신고 지연·사후 취소/정정 가능. 최신성·완전성·집계 준비 상태 별도 노출.
