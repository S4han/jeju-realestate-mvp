# Phase 2 분석 지표 및 산식 정의

> 상태: 최종 승인 반영 설계 문서 / 실제 API·DB·요금제 검증 및 구현 미수행. Claude Code에서 현행 코드 확인 후 수행.
> 범위: Phase 2 신규 파일만 추가. Phase 1 파일 수정 금지. 기능 플래그 기본 OFF. 사용자 수동 공개 승인 필수.

## 공통 집계 모집단
제주시·서귀포시, 매매, 해당 단지의 **확정 매칭**, 유효·최신 정정본, 취소 제외, 중복 제거, 계약일 유효, 원 단위 가격>0, 전용면적>0. 동일 거래 식별/취소·정정 연결은 실제 원천 응답 검증 후 확정. 표시 거래와 계산 거래에 같은 모집단 필터 적용.

## 기간·면적
한국시간 현재 월 포함 N개 계약월, [시작월 1일, 다음달 1일) 반열림 구간. 면적 유형은 정확한 decimal 기준 floor(area+0.5). 같은 단지라도 다른 면적 유형은 가격 통계 혼합 금지. 전체 면적은 월별/기간별 거래 건수만 제공.

## MET-001~008
- 001 중위 거래가격: 유효 거래 원화 가격 정렬 후 중앙값. 짝수는 중간 두 값 평균. 분기/기간 표본 3 미만 시 null(v1.1: 월별 중위 미사용).
- 002/003 최고·최저: 유효 거래의 MAX/MIN, 표본 수와 상태를 함께 표시. 표본 부족 시 최고/최저 공개 여부는 UI에서 표본 경고를 동반.
- 004 월별 거래량: 유효 거래 건수; 정상 수집 0과 수집 미확인 구분.
- 005 ㎡당 중위 거래가격: 각 거래의 sale_price_won / **원본** area_m2 값을 구한 후 중앙값. 단위 원/㎡, 표본 3 이상.
- 006 변화율: (최근12개월 중위−직전12개월 중위)/직전12개월 중위×100. 두 기간 각 3건 이상, 완전성 검증, 분모>0 필수. 현재 월 잠정 표시.
- 007 표본 수: 실제 모집단 거래 건수. 가격 숨김 월에도 건수 공개.
- 008 최신성: 마지막 정상 수집 시각, 대상 월 커버리지, 누락 월, 진행 중 월, 48시간 초과 경고.

## 엄격한 집계 원칙
월별·분기별 중위값의 중앙값 ≠ 기간 전체 거래 중위값. 기간 전체는 **원본 거래**로 재계산. 예: 월 A 3건(1,2,3), 월 B 5건(100,101,102,103,104)이면 월별 중위 2와 102의 중앙값 52는 전체 8건 중위 100.5와 다름.
