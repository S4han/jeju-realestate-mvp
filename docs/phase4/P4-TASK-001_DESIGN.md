# P4-TASK-001 AI 지역 요약 — 현행 분석·설계

작성 2026-10-26. 상태: **설계 초안, 결정 대기**(7절). 이 단계에서 AI API 호출·비밀값·DB·배포 변경 없음. ✅ 확인 · ⬜ 미확인 · ⚠ 주의.

## 1. 목표와 범위
- 지역 분석 화면 위에 **"이번 데이터 요약"** 카드(3~5문장)를 보여 준다. 대상: 제주 전체·제주시·서귀포시 3곳.
- 문장은 **코드가 계산한 사실만** 담는다. AI는 사실 목록을 읽기 쉬운 문장으로 정리할 뿐 숫자를 만들지 않는다.
- **하지 않음**: 원인 추정("개발 호재 때문에"), 가격 예측, 매수·매도 권유, 개별 단지 추천, 사용자 질문 응답(대화형은 범위 밖).
- 하루 1회, 새벽 자동 수집 직후 생성해 DB에 저장하고 웹은 읽기만 한다. 사용자 요청으로는 AI를 호출하지 않는다.

## 4. 사실 목록 (코드가 계산, 같은 데이터면 항상 같은 결과)
비교 기준: Phase 3와 동일한 **최근 12개월 vs 직전 12개월**(24개월 창), 확정 단지의 유효 매매, ㎡당 중위가격.
| ID | 사실 | 포함 조건 |
|---|---|---|
| F1 | 범위 전체 거래 건수 변화(최근·직전·증감률) | 항상 |
| F2 | 범위 전체 ㎡당 중위가격과 1년 전 대비 | 양쪽 3건 이상 |
| F3 | 상승 상위 3곳 / 하락 상위 3곳(읍면동) | 양쪽 기간 각 **10건 이상**인 곳만 |
| F4 | 거래가 가장 많은 읍면동 3곳(최근 12개월) | 거래 있는 곳 |
| F5 | 거래 건수 변화가 큰 곳(직전 10건 이상, ±30% 이상) | 해당 시 |
| F6 | **주의 대상**: 변화율 ±20% 이상인데 한쪽이 10건 미만(예: 2026-10-25 기준 표선면 +91.8%, 6건→11건) | 해당 시, 문장에 "표본이 적어 크게 달라질 수 있음" 필수 |
| F7 | 단지 미확정으로 지역 통계에서 빠진 거래 건수 | 1건 이상 |
| F8 | (D4 선택 시) **같은 단지끼리 비교한 변화율** — 두 기간 모두 거래된 단지만 | 양쪽 3건 이상 단지가 5곳 이상 |
- **생성 중단 조건**: 범위 안 수집 누락·부분 수집 달이 있거나(`completeness ≠ COMPLETE`) 데이터가 48시간 넘게 지연(`STALE`)이면 요약을 만들지 않는다(카드 숨김). 불확실한 상태를 문장으로 덮지 않기 위함.
- 각 사실은 `{id, label, value, display}` 형태. `display`(예: "434만원/㎡", "−8.6%", "1,396건")는 코드가 만든 표시 문자열.
- 사실 계산은 P4-TASK-002에서 독립 SQL과 대사(Phase 3 P3-TASK-007 방식).

## 5. AI 호출과 안전장치
**숫자 처리 — 자리표시자 방식(D3 권장)**
- AI에게는 사실 목록을 주고, 문장 안의 숫자 자리에 `{F2.change}` 같은 **자리표시자만** 쓰게 한다. 응답은 구조화 출력(JSON 스키마: 문장 배열, 각 문장이 쓴 사실 ID)으로 받는다.
- 서버가 자리표시자를 코드의 `display` 값으로 바꾼다. → AI가 숫자를 지어낼 경로가 없다.
- 검증(하나라도 실패하면 저장하지 않음): 원문에 숫자(0-9) 직접 포함, 없는 사실 ID, F6 해당 시 주의 문구 누락, 금지 표현(전망·예상·오를·내릴·투자·추천·매수·매도·때문·호재·악재), 문장 수 3~5 밖, 문장당 120자 초과.

**프롬프트 원칙**: 사실 목록에 없는 내용 금지, 원인·전망·권유 금지, 존댓말 서술, 표본 주의 대상은 반드시 함께 언급. 사실 목록은 데이터로만 취급(지역명은 공식 코드표 출처라 외부 텍스트 주입 위험 낮음).

**과금 차단(D7, 공개 조건)**
1. Anthropic 콘솔: 선불 크레딧 소액 충전 + **자동 충전 끔** + (가능하면) 워크스페이스 월 지출 한도. ⬜ 계정 화면 확인 필요.
2. 앱 상한: 기존 호출 예산 장치(`api_usage`, 수집과 같은 방식)로 출처 `ANTHROPIC` **하루 5회**, 호출당 `max_tokens` 1,500.
3. 플래그 `PHASE4_AI_SUMMARY_ENABLED`(기본 OFF) + `ANTHROPIC_API_KEY`(Production 전용 sensitive, 사용자가 대시보드에서 입력). 둘 중 하나라도 없으면 AI 호출 0.
4. 사용자 요청 경로에는 AI 호출 코드가 없음(읽기 API는 DB만 조회).
