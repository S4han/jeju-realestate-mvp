# P4-TASK-002 AI 요약 사실 목록 계산

작성 2026-10-26. 결정: P4-D1~D7 권장안 승인(2026-10-26). 이 단계에서 AI 호출·비밀값·운영 DB·배포 변경 없음.

## 1. 구현
- `server/phase4/facts.ts`
  - `loadFacts(pool, scope, now)`: 활성 지역 세트로 **읽기 전용 스냅샷 하나** 안에서 Phase 3 `loadRegionStats`(수정 없이 import)를 시·읍면동 단위로 읽고 사실 목록을 만든다. 범위 `JEJU | 50110 | 50130`.
  - `buildFacts(input)`: 순수 함수(같은 입력 → 같은 결과). 동률은 지역 코드 순.
  - `loadSameComplex(...)`: 같은 단지 비교(P4-D4) — 두 기간 각각 3건 이상 거래된 단지별 ㎡당 중위가격 비율의 중앙값, 읍면동·시 단위.
- 비교 기준은 Phase 3 "1년 전 대비"와 같은 **최근 12개월 vs 직전 12개월**. `period 12`로 읽어 데이터 버전(`snapshotId`)이 12·24개월 화면과 같다.
- `scripts/phase4/facts.ts`: 사실 목록 출력(읽기 전용, `--json` 지원) — 대사·검토용.

## 2. 사실 종류와 조건 (설계 4절 → 구현 ID)
| 설계 | ID | 조건 |
|---|---|---|
| F1 | `C{시}.count` | 항상: 최근·직전 건수, 직전 > 0이면 증감률 |
| F2 | `C{시}.price` | 양쪽 3건 이상 |
| F3 | `UP1~3`, `DOWN1~3` | 양쪽 각 **10건 이상**, 상승·하락 각 상위 3 |
| F4 | `VOL1~3` | 최근 12개월 거래 상위 3 |
| F5 | `SHIFT1~3` | 직전 10건 이상, 건수 ±30% 이상, 크기순 3 |
| F6 | `SMALL1~3` | 변화율 ±20% 이상이면서 한쪽 10건 미만 |
| F7 | `C{시}.unmapped` | 단지 미확정으로 지역 통계에서 빠진 거래(최근 12개월) |
| F8 | `SAME.{코드}` | F2·F3·F6에 나온 시·읍면동 중 대상 단지 **5곳 이상** |
- 모든 숫자는 `{value, display}`로 코드가 표시 문자열을 만든다(예: "520만원/㎡", "+73.3%", "-10.0%", "1,396건", "6곳").
- **생성 중단**: 범위 안 시의 최근 12개월에 수집 누락·부분 수집이 있거나, 1년 전 비교 구간이 불완전하거나, 48시간 넘게 지연되면 `ok: false`(카드 숨김). 다른 시의 누락은 영향 없음(Phase 3 TC-020과 같은 원칙).

## 3. 설계에서 바뀐 점 (구현 중 발견)
- ⚠ **신고 지연 편향**: 최근 12개월에는 아직 신고 기한(계약 후 30일)이 안 지난 1~2개월이 포함되어 거래 건수가 덜 집계된다 → 건수 감소가 실제보다 크게 보일 수 있다. 대책: 코드가 쓰는 **고정 주의 문구**(`notes`)를 요약 아래에 항상 붙인다. AI가 쓰는 것이 아니라서 빠질 수 없다.
- 주의 문구도 코드가 고정(AI 문장 검증 대상에서 제외): 비교 기준·기간, 신고 지연, (해당 시) 표본 적음, (해당 시) 같은 단지 기준 설명. → 설계 5절의 "F6 해당 시 주의 문구 누락 검증"은 이 고정 문구로 대체.
- 범위 판단: 시 범위(예: 서귀포시)는 그 시의 수집 상태만 본다(초안의 "어느 시든 누락이면 중단"보다 좁게).
