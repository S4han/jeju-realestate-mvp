# 좌표 육안 검증 표본 (2026-10-24)

연속지적도(AL_D002_50_20261008) 필지 중심점으로 계산한 좌표를 사람이 지도에서 직접 확인하기 위한 표본이다. 대단지 상위, 서귀포시, 중소 단지를 섞어 18곳을 골랐다.
