## 3. 코드 이력(TC-005) 처리
- ⚠ 공식 코드 파일은 **현존 코드만** 제공(폐지·변경 이력 없음). 시군구 단위 과거 코드 이력 공식 파일은 이번 조사에서 찾지 못함.
- 실무 영향 평가: 분석 기간은 2023-11 이후. 운영 DB의 확정 유효 매매 6,316건 모두 거래 코드 = 단지 코드(P3-TASK-001 10절).
- 처리안: ① 적재 시 **DB에 나타나는 모든 단지·거래 코드가 현행 코드표에 존재하는지** 검사, ② 없으면 해당 단지·거래를 MAPPING_UNVERIFIED로 격리·건수 표시(자동 연결 금지), ③ 코드표·경계 버전과 기준일을 저장해 다음 갱신 때 사라진 코드 목록을 비교. → TC-005는 "현행 코드표에 없는 코드 격리" fixture로 검증.

## 4. 좌표계·변환
- ⬜ 법정구역정보 SHP의 좌표계는 내려받은 `.prj`로 확인 필요(국내 공식 경계는 보통 GRS80 기반 TM 계열 — EPSG:5186/5179 등). 카카오맵은 위경도(WGS84) 사용.
- 변환 방법(추천): Phase 3 스크립트에 해당 TM 역변환식을 직접 구현(외부 패키지 추가 없음 → `package.json`(Phase 1) 변경 없음) + 검증.
- **강한 검증 수단(운영 데이터 활용)**: 좌표가 검증된 단지(`VERIFIED_PARCEL`)가 자기 `legal_dong_code` 읍면동 폴리곤 안에 들어가는지 전수 검사 → 변환 오류·코드-경계 불일치를 동시에 발견.

## 5. 크기·성능 추정(⬜ 실측 전)
- 대상: 제주 시 2개 + 법정 읍면동 전체(아파트 있는 곳 51곳 + 없는 곳).
- 원본 해안선이 복잡해 원본은 수 MB일 수 있음 → 읍면동 단위 단순화(허용오차 수십 m) 후 화면용 GeoJSON 목표 **300KB 이하(압축 100KB 이하)**. 원본 checksum과 단순화 버전을 함께 저장.
- 지도에는 선택한 시의 읍면동만 그림(카카오 폴리곤, 수십 개 수준).

## 7. 남은 확인 — 사용자 도움 필요
1. **브이월드에서 제주 법정구역 경계 내려받기(사용자 PC)**: 브이월드 로그인 → 공간정보 다운로드에서 "행정구역 읍면동(법정동)"의 **제주** SHP 파일(예: `LSMD_ADM_SECT_UMD_제주.zip`)과 "행정구역 시군구" 제주 SHP. 다운로드 화면의 **이용조건/라이선스 표기**를 캡처.
2. 내려받은 zip을 이 대화에 첨부(공개 저장소에 커밋하지 않고 검증용으로만 사용). 첨부가 어려우면 PC에서 돌릴 변환·검증 스크립트를 만들어 드림.
3. **법정동 코드 CSV 내려받기 승인**: 공공데이터포털 공개 파일(로그인·인증키 불필요)을 이 작업 환경에서 1회 내려받아 제주 부분만 검증에 사용(원본 파일은 커밋하지 않음).
