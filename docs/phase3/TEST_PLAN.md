## 2. 추가 필수 통합 검증
지역 거래 아파트 목록 정렬/커서, 두 지역 비교의 표본·완전성, 경계 GeoJSON 유효성·좌표계·라이선스, 동시 요청과 원자적 전환, 캐시 장애, 48시간 지연, 월 0원 공급자 한도, Phase 1·2 회귀, 접근성, 모바일 성능. 40건 외 발견 결함에 대한 회귀 케이스 추가.

## 3. 테스트 데이터
최소 0/1/2/3/4건, 짝수 중앙값, 서로 다른 면적, 동률 가격, 취소/정정/중복, 코드 변경, 미매핑, 수집 누락, 현재 월 잠정, 가격 변화율 분모·기간 경계, 지역 수 <5, 동시 집계 실패, 캐시 혼합 버전 등 결정적 fixture 작성. 실제 데이터와 가상 fixture 구분.

각 케이스 입력·기대·실제·PASS/FAIL·커밋 SHA·실행 시각·스크린샷/로그(Secret 마스킹) 기록. 40/40 통과, 데이터 대사 100%, Phase 1·2 회귀 통과, 지도·API 성능 목표 측정, 과금 차단 검증, 장애 복구 시연, 사용자 **수동 승인** 후만 공개. 하나라도 미검증이면 기능 OFF.
