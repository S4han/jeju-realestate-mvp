# Phase 3 — 지역 분석 정의 및 통계 계약

> 상태: STEP 6 최종 승인 반영 / 문서 확정. 실제 API·DB·공급자 요금·경계 라이선스 검증 및 개발·테스트는 **미수행**이며 Claude Code 책임 작업.
> 변경 경계: **docs/phase3/** 및 **tasks/phase3/** 신규 파일만. Phase 1·2 기존 파일·API·데이터 변경 금지. 기능 플래그 기본 OFF, 공개 전 사용자 수동 승인.
> 기준: 한국시간(Asia/Seoul), 아파트 **매매** 계약일 기준. 샘플 숫자는 실거래 아님.

## 확정 정책
- 지역: 제주시·서귀포시와 공식 **법정 읍·면·동**. 법정리·하위 법정동은 공식 계층표로 표시 수준에 상향 매핑; 행정동 혼용 금지.
- 지도: 검증된 공식 경계 DB 저장 후 API 제공; 지역별 색상(기본 거래별 **원/㎡ 중앙값**, 전환 거래량), 상세 카드.
- 기간: 현재 한국시간 계약월 포함 12/24/36개월, 기본 24개월. 현재 월 잠정; 기간 경계 [시작일, 다음월 첫날) 반개구간.
- 최소 유효 거래 3건이면 가격 표시, 1~2건은 거래량만, 0건은 수집 완전성이 입증된 경우만 '거래 없음'. 수집 실패는 미확인.
- 5분위: 같은 지도 범위·기간·지표 내 유효 지역만, 동일 값 분할 금지; 유효 지역 부족 시 가능한 등급만. 범례 실제 경계·대상 지역 수 표시. 거래량 전환 시 거래량 분포 재분류.
- MVP: 두 지역 동일 기간·버전 비교, 최근 12개월 대 직전 12개월 원/㎡ 중위값 변화율(각 기간 >=3, 완전성 필수), 해당 기간 거래 아파트 우선 목록, Phase 1·2 링크.
- 집계: 월별 **거래량 사전 집계**, 기간 **가격 중앙값 원본 유효 거래 계산**. 월별 중앙값의 평균/중앙값 재집계 금지.
- 최신성: 마지막 정상 수집 48시간 초과 경고. 비용 위험 시 비필수 작업 중단, 이전 검증 버전만 지연 표시 제공; 정합성 오류 버전 제공 금지.
- 공개: 검증 완료 스냅샷을 원자적으로 활성 버전 교체; 테스트 증거 검토 및 사용자 수동 승인 전 배포/플래그 활성화 금지.

## 1. 지역·기간
시 2개와 공식 법정 읍면동 계층 사용. 법정리·하위 법정동을 읍면동 표시 단위로 공식 계층에 따라 매핑. 원본 코드·유효기간·현재 표시지역 변환 정책을 기록하고 시점 변경/폐지 이력을 검증한다. 기준 계약월은 KST 현재 월 포함 최근 N개 월. 예: 24개월이면 현재 월 포함 24개 계약월. 기간 종료는 다음 달 1일 미만.

## 2. 유효 거래 필터
Phase 2와 같은 확정 단지 매칭, 유효 매매, 취소 제외, 정정 최신본, 중복 제거. 가격 원화>0, 전용면적㎡>0, 지역 확정 매핑. 거래 식별자는 Phase 2 정규화 ID 재사용; 임의 아파트명 매칭 금지. 제외 사유·건수 집계.

## 3. 산식
- 각 거래 원/㎡ = 원화 매매가격 / **원본 정밀 전용면적㎡**. 계산 과정에서 조기 반올림 금지.
- 지역 기간 중위값 = 해당 기간 유효 거래의 원/㎡ 중앙값(짝수는 중앙 두 값 평균). 최소 3건.
- 거래량 = 유효 거래 개수; 월별 사전 집계 후 기간 합산. 월별 중위값의 평균·중앙값으로 기간 가격 대체 금지.
- 시 가격은 하위 읍면동 가격의 평균이 아닌 시 원본 거래에서 직접 중앙값 계산.
- 변화율 = (최근 12개월 원/㎡ 중위값 - 직전 12개월 원/㎡ 중위값) / 직전 12개월 원/㎡ 중위값 × 100. 각 기간 >=3, 분모 양수, 두 기간 완전성 필요. 12개월 화면 선택에도 비교용 24개월 원천 필요. 최근 기간은 기준월 포함 12개월, 직전 기간은 그 이전 12개월.
- 비교: 두 지역의 동일한 계약기간·원본 필터·공개 스냅샷, 표본 상태와 기간 완전성 동시 표시.

## 4. 상태 우선순위
DATA_INCONSISTENT / SOURCE_INCOMPLETE / MAPPING_UNVERIFIED / STALE / PROVISIONAL / INSUFFICIENT_SAMPLE / NO_TRADES / AVAILABLE 등을 개별 축으로 표현. 데이터 수집 실패를 0건으로 변환 금지. 0건은 완전성 확인 시만; 1~2건은 거래량 제공·가격 비표시. 48시간 초과는 STALE 경고와 검증된 기존 버전 표기. 지연은 곧바로 모든 수치를 무효화하지 않지만 미검증 데이터는 제공 금지.

## 5. 지도 분위
표시 중인 **동일 레벨/상위지역/기간/지표**의 유효 지역 통계값 정렬; 5분위 경계 산출, 동률을 임의로 분리하지 않음. 유효 지역 <5개 또는 유일 값 <5개면 축소 구간. 범례에 실제 수치 범위·단위·유효 지역 수·기준 데이터 버전·분류법 표시. 표본 부족/누락은 별도 무채색·패턴 및 텍스트. 지도 범위 변화로 분위 재계산 시 범례가 바뀐다는 안내.

## 6. 지역 아파트 목록
선택 기간 유효 거래 존재·확정 지역 매핑 단지 우선, 최신 계약일 내림차순 + 단지 ID 보조 정렬. 서버 커서 페이지네이션; Phase 1 ID 링크, Phase 2 활성화 여부에 따라 링크 제공. 거래 없는 등록 아파트는 기본 목록에 섞지 않음.
