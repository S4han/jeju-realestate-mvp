# Phase 3 — 집계·지도·캐시 아키텍처

> 상태: STEP 6 최종 승인 반영 / 문서 확정. 실제 API·DB·공급자 요금·경계 라이선스 검증 및 개발·테스트는 **미수행**이며 Claude Code 책임 작업.
> 변경 경계: **docs/phase3/** 및 **tasks/phase3/** 신규 파일만. Phase 1·2 기존 파일·API·데이터 변경 금지. 기능 플래그 기본 OFF, 공개 전 사용자 수동 승인.
> 기준: 한국시간(Asia/Seoul), 아파트 **매매** 계약일 기준. 샘플 숫자는 실거래 아님.

## 확정 정책
- 지역: 제주시·서귀포시와 공식 **법정 읍·면·동**. 법정리·하위 법정동은 공식 계층표로 표시 수준에 상향 매핑; 행정동 혼용 금지.
- 지도: 검증된 공식 경계 DB 저장 후 API 제공; 지역별 색상(기본 거래별 **원/㎡ 중앙값**, 전환 거래량), 상세 카드.
- 기간: 현재 한국시간 계약월 포함 12/24/36개월, 기본 24개월. 현재 월 잠정; 기간 경계 [시작일, 다음월 첫날) 반개구간.
- 최소 유효 거래 3건이면 가격 표시, 1~2건은 거래량만, 0건은 수집 완전성이 입증된 경우만 '거래 없음'. 수집 실패는 미확인.
- 5분위: 같은 지도 범위·기간·지표 내 유효 지역만, 동일 값 분할 금지; 유효 지역 부족 시 가능한 등급만. 범례 실제 경계·대상 지역 수 표시. 거래량 전환 시 거래량 분포 재분류.
- MVP: 두 지역 동일 기간·버전 비교, 최근 12개월 대 직전 12개월 원/㎡ 중위값 변화율(각 기간 >=3, 완전성 필수), 해당 기간 거래 아파트 우선 목록, Phase 1·2 링크.
- 집계: 월별 **거래량 사전 집계**, 기간 **가격 중앙값 원본 유효 거래 계산**. 월별 중앙값의 평균/중앙값 재집계 금지.
- 최신성: 마지막 정상 수집 48시간 초과 경고. 비용 위험 시 비필수 작업 중단, 이전 검증 버전만 지연 표시 제공; 정합성 오류 버전 제공 금지.
- 공개: 검증 완료 스냅샷을 원자적으로 활성 버전 교체; 테스트 증거 검토 및 사용자 수동 승인 전 배포/플래그 활성화 금지.

## 1. 흐름
Phase 1 거래·단지 데이터(읽기 전용) → Phase 2 유효 거래 판정 재사용 → 공식 법정코드·지역 매핑 → 월별 거래량 사전 집계 및 원본 기간 중위값 계산 → 스냅샷 검증 → ACTIVE 원자적 전환 → /api/v3 지도·카드·비교·목록 → 모바일 UI. 공식 경계는 출처/라이선스 검증 후 DB에 버전 저장, API에서 단순화·압축 제공.

## 2. 혼합 집계
월별 거래량은 region_id×contract_month×snapshot_id 기준 사전 계산; 12/24/36개월 합산. 가격은 해당 기간 원본 유효 거래별 price_won/area_m2의 중앙값을 DB/서버의 정확한 median 연산으로 계산. DB에서 median 지원이 없으면 정렬 중앙 인덱스 방식 구현 및 검증. 변화율은 두 12개월 원본 계산. 거래 변경 시 영향 계약월·읍면동·상위 시 및 비교·범례 갱신.

## 3. 스냅샷 공개 프로토콜
1) 새 immutable snapshot 생성(원천 watermark, 코드/경계 버전 고정)
2) 지역 매핑·월별 건수·가격·변화율·범례 계산
3) 완전성/시-읍면동 대사/표본/동률/성능·비용 검증
4) 실패 시 스냅샷 REJECTED, ACTIVE 유지
5) 검증 성공 시 **단일 트랜잭션/원자적 포인터 CAS**로 ACTIVE 교체
6) API 요청 시작 시 활성 snapshotId를 고정해 일관된 조회; 클라이언트 후속 조회에서 버전 확인
7) 이전 정상 스냅샷 보존 정책과 롤백 절차 운영. 실제 스토리지의 원자성 지원 여부는 Claude Code 검증 필수; 불가 시 공개 차단.

## 4. 캐시
키 예: p3:map:{level}:{parent}:{period}:{metric}:{snapshotId}:{boundaryVersion}; p3:region:{id}:{period}:{snapshotId}; p3:compare:{sortedIds}:{period}:{snapshotId}. 버전 키로 불변 캐시, TTL·저장량 상한·요청당 계산 제한. 클라이언트·서버·DB 캐시가 서로 다른 버전이면 409/재조회. 유료 Redis 필수 전제 금지.

## 5. 경계·지도
경계 원본은 검증된 DB 저장, 화면 확대 수준별 단순화 폴리곤 파생본은 원본 checksum과 연결. 지도 공급자 이용조건·무료 한도·폴리곤 라이선스 확인 전 공개 금지. 지도 SDK 오류 시 API 기반 목록/표 대체. 표시 범위에 따른 5분위 범례는 단일 스냅샷에서 계산.

## 6. 격리
Phase 3 전용 네임스페이스/라우트/마이그레이션/기능 플래그. 쿼리 시간·동시성·집계 작업 상한, Phase 1·2 회귀 검증. 사용자 지도 이동 때 외부 실거래 API 직접 호출 금지.
