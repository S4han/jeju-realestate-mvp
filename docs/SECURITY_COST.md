# 보안·비용·성능·장애 정책

## 보안
- 공공데이터 인증키·DB 접속정보는 서버/CI Secret으로만 관리. 프론트 번들·로그·GitHub에 노출 금지.
- 카카오맵 브라우저 앱 키는 공개 식별자로 취급하고 허용 도메인 등록/사용 제한.
- 지역코드(50110, 50130), bbox, 기간, 정렬, 페이지 크기 등 서버 검증. DB 쿼리 파라미터화.
- 회원가입 없음, 위치·검색어 장기 저장 금지, 기본 호스팅 로그 정책 확인.

## 월 0원
- 공급자별 무료 한도, 이용조건, 자동 과금 여부 확인 전 공개 운영 금지.
- 내부 호출 예산 80% 경고, 한도/예상 초과 시 외부 호출 차단. 공급자 제한보다 안전 여유 확보.
- 브라우저 지도 SDK 호출은 서버 API 차단만으로 비용 통제가 불가능하므로 공급자 과금 차단 별도 검증.
- 위험 기능은 공개 보류하고 대체 UI 제공.

## 성능 잠정 목표(실측 전)
자동완성 p95 500ms, 지도 마커 API p95 800ms, 단지 상세 API p95 800ms, 거래목록 API p95 1초, LCP p75 2.5초. 실측 환경 기록.

## 오류
지도 오류→목록 검색; 수집 실패→마지막 정상 데이터+지연 안내; 일부 월 누락→누락 기간 표시; 거래 없음과 장애 구분; DB 장애→안전한 오류.

## 수집
일 1회 최근 기간 갱신, 과거 기간 정기 재검증, 취소·정정 반영, 동일 데이터 재수집 중복 방지. 무료 한도 우선.
