# 제주 부동산 실거래 통합 검색 PRD v1.0

- 문서 상태: **확정** (STEP 1~6 승인)
- 실제 API 연결/응답/가격 검증: **미수행**, Claude Code 또는 Codex 단계로 이관

## 목표 및 범위
제주시·서귀포시의 아파트를 지도와 아파트명 자동완성으로 탐색하고 최근 12개월 매매·전월세 실거래를 확인하는 모바일 웹. 첫 화면은 제주 지도 + 상단 검색창. 현재 지도 화면 영역에 위치 검증된 아파트 마커 표시, 클릭 시 단지 요약 카드, 상세보기에서 확정 매칭된 거래만 표시.

## 승인 결정
- 지역: 제주시(50110)·서귀포시(50130)
- 기간: 현재 월 포함 최근 12개 계약월
- 기능: 이름 검색/자동완성, 지역/기간, 지도 마커/영역 갱신, 단지 요약, 거래 상세/필터/정렬, 출처·갱신시각
- 지도: 카카오맵 JavaScript SDK 우선 검토, 과금/약관 확인 전 공개 확정 금지
- 단지: 한국부동산원 단지 기본정보 + K-APT 보완; 주소·좌표 별도 검증
- 매칭: 공식 식별자/주소/법정동/지번/단지명 검증. 불확실 건은 단지 상세에서 제외하고 내부 관리
- 기술: React + TypeScript + Vite + Tailwind; TypeScript API Routes; PostgreSQL 무료 DB 우선 검토
- 수집: 초기 전체 수집, 최근 기간 일 1회 증분/반복 수집, 과거 정기 재검증; 사용자 조회 시 원천 API 직접 호출 금지
- 운영: 월 0원 목표, 유료 전환 위험 기능 공개 보류; 갱신 실패 시 마지막 정상 데이터 + 지연 안내
- 개인정보: 회원가입 없이 검색, 최소 수집

## 화면
- SCR-001 지도 검색 홈: 이름 자동완성, 시 선택, 지도/마커
- SCR-002 마커 선택 요약 카드: 단지명, 주소, 확인된 최근 거래 요약, 상세 이동
- SCR-003 거래 상세: 최근 12개월 매매/전월세, 계약일·면적·층·금액, 필터/정렬, 출처·최신성
- SCR-004 지도 장애 시 목록 검색 대체

## 수용 원칙
- 동명 단지는 주소로 구분; 지도 좌표가 검증되지 않으면 마커 생성 금지.
- 거래가 없다는 상태와 수집 실패·일부 기간 누락은 별도로 표시.
- 거래 금액·면적·계약일·층·출처 표시; 전월세 보증금과 월세를 분리.
- 매칭 후보 복수/주소 충돌/이름만 일치는 자동 연결 금지.
- 데이터 취소·정정·중복 수집을 반영; 원천 고유키 유무는 실제 응답으로 확인.
- 무료 쿼터와 공급자 과금 차단이 검증되지 않으면 공개 운영 보류.

## MVP 제외
가격 추이 그래프, 즐겨찾기, 알림, 토지/오피스텔, AI 예측, 로그인. 클러스터링 고도화는 후속이나 기본 밀집 처리는 성능 확보 범위 내 포함.
